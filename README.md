# Fennmark Analytics
End-to-end analytics for a direct-to-consumer merchandise and apparel brand: public GA4 app
events joined to a generated booking backend, modelled with dbt on BigQuery.

**Status:** Phase 0, complete (week 2 of 16).

Stack: BigQuery, dbt, GitHub Actions, Tableau Public, Python
